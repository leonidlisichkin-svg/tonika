# 3.3 Decision lists: trainer and pack

**Roadmap:** Phase 3. **Needs Leo:** nothing. **After:** 3.2.
**Spec:** [`docs/specs/decision-lists.md`](../specs/decision-lists.md), all but "The layer".

## Goal

A pack that learns readings from the examples by counting, explains each decision by a rule, and
is rebuilt in seconds. Pure Python, no new dependency.

## Read first

The spec, in full. `src/tonika/packs/base.py`, `src/tonika/packs/fake.py`, `src/tonika/text.py`,
`src/tonika/data.py` from 3.1.

## Build

- `src/tonika/learn.py`: features, counting, thresholds, ordering, writing and reading the model
  file exactly as specified.
- `src/tonika/packs/decision_lists.py`: `DecisionListPack`.
- `tonika data train <examples> --out <file>` and `--report` (5-fold, fixed split).
- `data/models/ru.dl.json` built from the seed examples and committed; a CI step rebuilds it and
  fails if the file differs.
- `get_pack(lang, "dl")` selects it by name. `"auto"` is unchanged in this item.
- Tests: the spec's acceptance points 1 to 4, 6 and 7.
- `docs/ARCHITECTURE.md`: replace "Universal pack (Phase 3)" with what now exists.

## Out of scope

Layering over the Russian model (3.4). Collection.

## Pitfalls

- Byte-identical output: sort everything, fix the float rounding, write with sorted keys.
- The trainer must refuse paths under `data/golden/`.
- Report cross-validated numbers, never numbers on the training examples themselves.

## Done when

`tonika data train data/examples/ru --report` prints coverage and precision, the committed model
reproduces in CI, and the pack passes its tests.
