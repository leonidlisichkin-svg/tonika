# 0.1 Listening test: which notation does the voice honour?

**Roadmap:** Phase 0, last item. **Needs Leo:** five minutes in Fliki.

## Goal

Know, by ear, which stress notation the channel's Fliki voice obeys, and record it as an engine
preset. Everything Tonika produces for the channel depends on this answer.

## Read first

`src/tonika/engines/` (a preset is one TOML file), `docs/DECISIONS.md`.

## Steps

1. Ask Leo which Fliki voice the channel uses (name and language as Fliki shows them).
2. Give him this text to paste into Fliki as one scene, with that voice, and ask him to listen.
   Each line pushes the stress to the **unnatural** place, so obedience is easy to hear.

   ```
   Я открыл замок ключом.
   Я открыл з+амок ключом.
   Я открыл за́мок ключом.
   Я открыл зАмок ключом.
   Белая мука лежала в мешке.
   Белая м+ука лежала в мешке.
   Белая му́ка лежала в мешке.
   Белая мУка лежала в мешке.
   ```

3. Ask, one question at a time:
   - Lines 2, 3, 4: in which of them did «замок» sound as **за́мок** (stress on «а»)?
   - Lines 6, 7, 8: in which did «мука» sound as **му́ка** (stress on «у»)?
   - Did the voice say «плюс» aloud, pause strangely, or spell a capital letter?
4. A notation is honoured only if it worked in both words with no side effect.

## Build

- `src/tonika/engines/fliki-<voice>.toml` with `notation`, `languages = ["ru"]`,
  `verified_by = "leonidlisichkin-svg"`, `verified_on` = today, and notes on what was heard.
- If no notation works: record that, set the preset to `yo` (ё only), and note in `DECISIONS.md`
  that this voice needs another route (Fliki's pronunciation map, or another voice).
- A `DECISIONS.md` entry with the result. Tick the roadmap item.
- A test that the new preset loads and resolves.

## Done when

`uv run tonika engines` lists the Fliki preset as verified, and Phase 0 is closed in the roadmap.
