# 1.1 Long-text trial, and the plan stops waiting on any engine

**Roadmap:** closes Phase 0; replaces item 1.1 of Phase 1. **Needs Leo:** nothing.

## Goal

Leo decided on 2026-11-17: Tonika is engine-neutral. No product, engine or single user gates a
phase, so the Fliki listening test (0.1) and the voiced script trial (old 1.1) are withdrawn.
In their place, a 30-minute public-domain text runs through the CLI in CI and proves that Tonika
changes nothing but pronunciation marks, with speed, memory and review load on record.

## Build

1. **Trial text.** `data/trials/ru/<slug>.txt`: complete Russian prose in modern orthography,
   30,000 to 45,000 characters, by an author who died before 1930, first published before 1931
   (Chekhov is the obvious choice). UTF-8, NFC, the author's text only.
   `data/trials/README.md`: author, title, year, source URL, date fetched, why it is public
   domain. Add the folder to `data/README.md` and to `LICENSES.md` before using it.
2. **`src/tonika/trial.py`.** `run_trial(text, pack, ...) -> TrialReport` with: characters, words,
   words marked, words with more than one reading (what `--review` lists) per 1,000 words,
   ё respellings, characters per second, peak memory, the model string, and `preserved` with
   the first differing position when false.
3. **Preservation check.** For every notation and every mode: undo the marks and the recorded
   respellings in the output and get the input back exactly, every space, line break,
   punctuation mark and letter case. Work from the Intent Document, not from guesses about the
   output string.
4. **CLI.** `tonika trial <file> [--lang] [--pack] [--format md|json]`; exit code 1 when the text
   is not preserved.
5. **Tests.** Offline on the whole trial text with `FakePack`: preservation in all notations and
   modes, and two runs give identical output. With `@pytest.mark.models`: the same with the real
   Russian pack.
6. **CI.** The `models` job runs `tonika trial` on the text, adds its table to the pull request
   comment and fails when the text is not preserved.
7. **`docs/TRIALS.md`.** The first trial: date, machine, model string, every number above.
8. Any bug the trial exposes: a failing test and the fix. If the fix is large, stop, report it
   and leave it for its own pull request.

## Out of scope

Improving the model. Labelling the trial text for accuracy. New engine presets. New
dependencies, services or accounts. Any change to `data/golden/`.

## Pitfalls

- Online editions carry footnotes, page numbers and editors' notes: strip them. Use no
  translation and no annotated edition; those have their own copyright.
- Stress marks already printed in the source are author marks (principle 5), not noise.
- `upper` changes letter case and a literal `+` may occur in text: the check must survive both.
- Assert on preservation and determinism, never on speed or memory; those are recorded only.
- Keep the offline test fast: it runs in every `check` job.
- If the Codespace cannot reach a source of the text, stop and tell Leo.

## Done when

`uv run tonika trial data/trials/ru/<slug>.txt` prints the report with the text preserved; the
pull request comment shows the same table; `ROADMAP.md` shows Phase 0 closed; `Fliki` appears
