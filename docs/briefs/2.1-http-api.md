# 2.1 HTTP API

**Roadmap:** Phase 2. **Needs Leo:** nothing. **Spec:** [`docs/specs/api-v1.md`](../specs/api-v1.md).

## Goal

`tonika serve` starts an HTTP server that does over the network exactly what the library does in
process. The web editor (2.3) and every later integration talk to it.

## Read first

The spec, in full. `src/tonika/pipeline.py`, `src/tonika/engines/__init__.py`,
`src/tonika/packs/__init__.py`, `src/tonika/cli.py`, `.github/workflows/ci.yml`.

## Build

- `pyproject.toml`: extra `api = ["fastapi>=0.115", "uvicorn>=0.30"]`; `httpx` in the dev group
  for the test client. These are in the agreed plan; anything else, ask Leo.
- `src/tonika/server/`: `create_app()`, the routes, pydantic request and response models, one
  error handler producing the spec's error body, settings read from the environment.
- `tonika serve --host --port` in `cli.py`. Import the server inside the command; without the
  extra, print `install it with: pip install 'tonika[api]'` and exit with code 2.
- Tests in `tests/server/`, starting with `pytest.importorskip("fastapi")`, covering the spec's
  eight acceptance points with `TONIKA_PACK=fake`.
- CI: the `check` job installs `--extra api`. The `models` job gets one test that posts a real
  sentence through the test client.
- `CLAUDE.md` (commands, layout), `README.md` (a short "HTTP API" section with one `curl`).

## Out of scope

The web editor, Docker, deployment, rate limits, API keys.

## Pitfalls

- The core must still import and pass its tests without the extra installed. Keep `mypy` strict
  for `src/tonika/server/` too.
- Do not log request bodies, including in validation errors: FastAPI's default 422 body echoes
  the input, so replace it with the spec's error body.
- `/v1/languages` and `/healthz` must not load models.
- Count the limit in code points after NFC, not in bytes.

## Done when

The eight acceptance points pass in CI, and in the Codespace
`curl -s localhost:8000/v1/annotate -H 'content-type: application/json' -d '{"text":"В старом замке сломался замок.","target":"plus"}'`
returns `В старом з+амке сломался зам+ок.`
