# 1.1 Script trial

**Roadmap:** Phase 1 exit. **Needs Leo:** one real script (about 30 minutes of speech), voicing
it, and noting every word that sounds wrong. **After:** 0.1, so the target notation is known.

## Goal

Measure Tonika on the real thing: how many stress errors remain in a voiced episode. Turn each
error into a permanent test.

## Read first

`docs/CODESPACES.md`, `docs/DICTIONARY.md`, `src/tonika/review.py`, `src/tonika/evaluate.py`,
`docs/DECISIONS.md` (D-016).

## Privacy

The script is Leo's work and stays out of the repository. Create `local/`, add it to `.gitignore`
first, and keep the script and all outputs there. Only single sentences that Leo approves go into
the public golden set (CC0).

## Steps with Leo, one at a time

1. He drags the script file into `local/` in the file list.
2. Run, with the engine preset from 0.1:
   `uv run tonika annotate -f local/episode.txt -o local/episode.marked.txt --target <preset> --review local/check.md`
3. Show him `local/check.md`: the words Tonika was unsure about. He fixes any he disagrees with
   by typing the stress in the script (`зам+ок`), and names and brands go into
   `local/names.txt` (dictionary format). Run again with `--dict local/names.txt`.
4. He voices `local/episode.marked.txt` in Fliki and listens once, noting each wrong word with a
   few words of context.
5. For each noted word, find the sentence and classify the error: wrong homograph, wrong ё,
   a name or rare word (dictionary), not a stress problem (the voice), or Tonika changed the text.

## Build

- `docs/TRIALS.md`: date, script length in characters and words, model string, engine preset,
  doubtful words shown, errors heard by class, errors per 1 000 words, minutes Leo spent.
- `data/golden/ru-scripts.txt`: the sentences with wrong homographs or ё, correctly marked, each
  approved by Leo for publication. Add it to the CI accuracy run next to `ru.txt`, with its own
  floor in `baseline.json` set to the accuracy measured now.
- Any bug found (text changed, crash, lost layout): a failing test and the fix.
- Tick the item; record the numbers in `DECISIONS.md`.

## Out of scope

Improving the model. This item only measures and records.

## Done when

`docs/TRIALS.md` holds the first trial, the second golden set is in CI, and Phase 1 is closed.
