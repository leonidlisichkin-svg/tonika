# 1.2 Compare the Russian models

**Roadmap:** Phase 1. **Needs Leo:** nothing.

## Goal

Choose the default Russian model on evidence. stressonnx 0.0.2 has three model ids (`ruaccent`,
`silero`, `simple`); Tonika uses its default for Russian, `ruaccent`, which scores 92.3% on
`data/golden/ru.txt`. If a stable stressonnx 0.0.3 exists by now, include its models too (its
pre-release added quantised and larger variants; see D-015) and bump the pin only on evidence.

## Read first

`src/tonika/packs/stressonnx.py`, `src/tonika/packs/__init__.py` (`"stressonnx:<model id>"`),
`docs/DECISIONS.md` (D-009, D-014, D-015), the stressonnx registry
(`uv run python -c "import stressonnx.registry as r; print(*r.MODEL_REGISTRY, sep='\n')"`).

## Build

1. In the Codespace (real models work there), for every model id that serves `ru`:
   `uv run tonika eval data/golden/ru.txt --pack stressonnx:<id> --format json`
   and the same on `data/golden/ru-scripts.txt` if 1.1 is done. Note peak memory
   (`/usr/bin/time -v`) and the download size.
2. `docs/ACCURACY.md`: one table, a row per model: accuracy on each golden set, characters per
   second, memory, download size, licence as its registry states it.
3. Choose: highest accuracy; within one percentage point, prefer the faster and smaller. If the
   choice differs from today's default, make it the default in `StressonnxPack`, raise the floor
   in `data/golden/baseline.json` to just under the new accuracy, and update `LICENSES.md` first
   if the model's licence differs. A non-commercial licence excludes a model outright.
4. `DECISIONS.md` entry with the table's headline numbers. Tick the item.

## Pitfalls

- Never pick a model by looking at which golden sentences it fixes. Only the totals count.
- CI runs only the default model. The table is measured in the Codespace; say so in the file,
  with the date and the machine size.
- A model id may fail to load for `ru`; record it as unavailable and continue.

## Done when

`docs/ACCURACY.md` exists, the default is justified in `DECISIONS.md`, CI is green.
