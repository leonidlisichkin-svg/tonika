# 1.2 Model choice and reproducibility

**Roadmap:** Phase 1, last item; closes Phase 1. **Needs Leo:** nothing.
Save this brief as `docs/briefs/1.2-model-comparison.md`, replacing the old one; update the
title in the `README.md` table.

## Goal

Close Phase 1 honestly. PR #5 found two gaps: `tonika annotate` drops CR from Windows line
endings, so the CLI does change the text, and one CI runner marked 3,181 words where every other
machine marked 3,183, so principle 4 does not hold as written. Fix the first, explain the second
and record the rule, then choose the default Russian model on evidence.

## Read first

`CLAUDE.md` (principle 4), `docs/TRIALS.md`, `docs/DECISIONS.md` (D-009, D-014, D-015, D-020),
`src/tonika/cli.py`, `src/tonika/trial.py`, `src/tonika/packs/stressonnx.py`,

(`uv run python -c "import stressonnx.registry as r; print(*r.MODEL_REGISTRY, sep='\n')"`).

## Build

1. **CR LF.** `tonika annotate` keeps every line ending exactly as given, from a file, from
   stdin and when writing `-o` or stdout. Tests: a CR LF file and CR LF stdin come back byte for
   byte, in text and JSON output. Then a trial-style check over the CLI itself: annotate the trial
   text converted to CR LF, undo the marks, compare bytes.
2. **Make drift visible.** Add to `TrialReport` and its table: the CPU model and instruction set
   level as the OS reports them (`/proc/cpuinfo` on Linux; "unknown" elsewhere, no new
   dependency) and `digest`, a SHA-256 of the Intent Document's tokens (sorted keys, no
   whitespace). The CI `models` job also saves the trial's Intent Document as a workflow
   artifact (`actions/upload-artifact`, GitHub's own; no new service).
3. **Find the two words.** Re-run CI until a runner with a different digest appears (at most
   three runs, via `workflow_dispatch` or an empty commit). Compare its artifact with the
   Codespace output: name the words, their sentences, both readings, and the CPU of each machine.
   If no differing runner shows up in three runs, say so and record what was seen.
4. **Look for a fix, briefly.** Check, in at most 30 minutes, whether stressonnx 0.0.2 lets us set
   onnxruntime session options (graph optimisation level, thread count) without patching it.
   If yes and it removes the drift at a cost under 20% in speed, apply it and say so. Never patch
   or fork stressonnx.
5. **D-021 and principle 4.** Record the conductor's decision, adjusted to the evidence from
   steps 3 and 4. Proposed wording for principle 4 in `CLAUDE.md`: "Deterministic: Tonika's own
   code gives bit-identical output on any machine. A neural backend gives identical output on the
   same machine and may differ across processors in close decisions; CI records the processor and
   the output digest, and such drift must stay under 0.1% of words given stress on the trial
   text. Every result names its model and data version."
6. **Model comparison** (the old 1.2). For every stressonnx model id that serves `ru` (and the
   models of a stable 0.0.3, if one is released by now): accuracy on `data/golden/ru.txt`, and
   `tonika trial` on the trial text (preserved, words to review per 1,000, speed, peak memory from
   the report: the Codespace has no `/usr/bin/time`), download size, licence as the registry
   states it. `docs/ACCURACY.md`: one table, the date and the machine. Choose: highest accuracy;
   within one percentage point, fewer words to review, then faster and smaller. If the default
   changes: make it the default, update `LICENSES.md` first if the licence differs, raise the
   floor in `baseline.json` to just under the new accuracy. A non-commercial licence excludes a
   model outright.
7. `DECISIONS.md` entries for the default model and D-021; `docs/TRIALS.md` updated; tick 1.2 and
   mark Phase 1 closed in `ROADMAP.md`.

## Out of scope

Training or tuning models. Changes to `data/golden/`. A new pack or backend. Pinning a
pre-release.

## Pitfalls

- Never choose a model by which golden sentences it fixes; only totals count.
- Python's text mode turns `\r\n` into `\n` on read and `\n` into `os.linesep` on write: control
  both ends.
- The digest must cover tokens only, never timings or the model load.
- A model id may fail to load for `ru`: record it as unavailable and go on.

## Done when

A CR LF file goes through `tonika annotate` byte for byte; the trial table in the pull request
comment shows CPU and digest; the two drift words are named in `docs/TRIALS.md` (or their
absence is recorded); D-021 is in `DECISIONS.md` and principle 4 in `CLAUDE.md` matches it;
`docs/ACCURACY.md` justifies the default; Phase 1 is closed; CI is green.
